# 🧠 Emotion Detection AI

A Deep Learning based Facial Emotion Recognition System built using TensorFlow, OpenCV and Streamlit.

## 🚀 Live Demo

https://emotion-detection-ai-rqzjekybr3dzajmj5dzxv8.streamlit.app/

## ✨ Features

- Upload Image Based Emotion Detection
- CNN Model Trained on FER-2013 Dataset
- Emotion Confidence Analysis
- Interactive Streamlit Dashboard
- Face Detection using OpenCV
- Cloud Deployment using Streamlit

## 🎭 Supported Emotions

- Angry 😠
- Disgust 🤢
- Fear 😨
- Happy 😊
- Neutral 😐
- Sad 😭
- Surprise 😲

## 🛠️ Tech Stack

- Python
- TensorFlow
- OpenCV
- Streamlit
- NumPy
- Pillow
